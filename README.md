# Remotion Video Project

This is a Remotion project for creating videos programmatically.

## Project Structure

```
├── src/
│   ├── index.tsx         # Entry point with Composition definition
│   └── Composition.tsx   # Video composition component
├── public/               # Static assets
├── package.json
├── tsconfig.json
└── tsconfig.node.json
```

## Available Scripts

- `npm start` - Preview the video in the browser
- `npm run build` - Render the video to MP4 file
- `npm run build-still` - Render a still frame to PNG

## Getting Started

1. Install dependencies (already done)
2. Run `npm start` to preview your video
3. Modify `src/Composition.tsx` to create your custom video
4. Run `npm run build` to render the final video
