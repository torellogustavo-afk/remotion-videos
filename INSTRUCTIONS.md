## ✏️ Cómo Personalizar

### **Cambiar Colores**
En `src/Composition.tsx`, busca:
```tsx
color: '#fbbf24',  // Cambiar a tu dorado
background: 'linear-gradient(135deg, #0f172a 0%, #1e293b 50%, #0f172a 100%)',  // Cambiar gradiente
```

### **Cambiar Textos**
En `src/Composition.tsx`, busca los elementos `<h1>`, `<h2>`, `<p>` y modifica directamente.

### **Cambiar Duraciones de Animaciones**
Busca `interpolate(frame, [inicio, fin], ...)` y ajusta los números.

### **Agregar Audio**
```tsx
import { Audio } from 'remotion';
<Audio src="/path/to/music.mp3" />
```

## 🔧 Troubleshooting

### **El preview.html no muestra animaciones**
→ Asegúrate que el navegador soporte CSS animations (modernos sí)

### **El video renderizado se ve diferente**
→ Verifica que FFmpeg esté instalado en tu sistema
→ Intenta: `npm install -D ffmpeg-static`

### **Quiero cambiar algo del video**
→ Edita `src/Composition.tsx` y vuelve a renderizar
→ Los cambios son inmediatos
